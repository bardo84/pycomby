                         ARCHITECTURE
================================================================================

CONTROL FLOW:
  Source Code + Pattern
      ↓
  Pattern Compilation
      ↓
  Pattern Matching (find positions)
      ↓
  [NEW] Extract @hint directives
      ↓
  [NEW] Detect context
      ↓
  [NEW] Resolve hints to values
      ↓
  [NEW] Registry lookup
      ↓
  Render template
      ↓
  Output Code

COMPONENT INTERACTIONS:
  pycomby.py
    ├─ Pattern matching (existing)
    ├─ Extract hints → semantic_resolver
    ├─ Detect context → context_detector
    ├─ Registry lookup → builtin_registry
    └─ Render template → all components

================================================================================
                           USAGE EXAMPLE
================================================================================

PYTHON API:

  from pycomby import pycomby
  from builtin_registry import load_registry
  from semantic_resolver import SemanticResolver

  # Load registry
  builtin_reg = load_registry('phase2_registry.json')
  resolver = SemanticResolver(builtin_reg)

  # Pattern with @hint
  pattern = '''
  provider::<:[module]>:::[func]
  @hint backend = detect_from_context()
  '''

  replacement = 'accel(":[func.lookup(backend)]")'

  # Apply transformation
  result = pycomby(
      code,
      pattern,
      replacement,
      builtin_registry=builtin_reg,
      semantic_resolver=resolver
  )
