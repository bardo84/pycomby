================================================================================
                         KEY FEATURES
================================================================================

FEATURE:        lookup operation
SYNTAX:         :[name.lookup]
CAPABILITY:     Resolve captured values via static registry
FALLBACK:       TODO_CONTEXT_{value} on missing key

EXAMPLE:
  Pattern:      provider::<:[func]>
  Replacement:  accel(":[func.lookup]")
  Registry:     {"builtin:atan": "builtins::math::trigonometry::atan::wgpu"}
  Result:       accel("builtins::math::trigonometry::atan::wgpu")

================================================================================
                         QUICK START
================================================================================

PYTHON API:
  from pycomby import pycomby
  import json
  
  registry = {"builtin:atan": "builtins::math::trigonometry::atan::wgpu"}
  result = pycomby(code, 'provider::<:[func]>', 'accel(":[func.lookup]")',
                   registry=registry)

CLI:
  pycomby -i code.txt 'provider::<:[func]>' 'accel(":[func.lookup]")' \
          --registry registry.json

REGISTRY (JSON):
  {"builtin:key": "resolved_value"}
